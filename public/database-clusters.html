Clustered Database Schema Overview

Normalized relational schema eliminating transitive dependencies across four domain clusters: Identity & Personal, Fleet & Business Assets, Operations & Transactions, and Philippine Pricing & Promotions.

Cluster 1

Identity & Personal (Users & Statutory Verification)

Separates authentication credentials from personal license data and Senior/PWD verification records.

3NF Rationale: Driver's license details and OSCA/NCDA statutory IDs depend on customer identity, not login sessions. Extracting them prevents NULL sprawl for admin/staff accounts.
usersAuth Core
  • PK idINT AUTO_INC
  • FK location_idINT NULL → locations
  • nameVARCHAR(120)
  • UQ emailVARCHAR(150)
  • password_hashVARCHAR(255)
  • account_statusENUM(pending..archived)
customer_profilesPersonal & License
  • PK idINT AUTO_INC
  • FKUQ user_idINT → users
  • date_of_birthDATE
  • UQ drivers_license_numberVARCHAR(50)
  • license_expiry_dateDATE
  • emergency_contact_nameVARCHAR(120)
  • emergency_contact_phoneVARCHAR(30)
customer_eligibility_verificationsSenior / PWD
  • PK idINT AUTO_INC
  • FK user_idINT → users
  • UQ eligibility_typeENUM(senior_citizen, pwd)
  • UQ id_numberVARCHAR(60)
  • issuing_authorityVARCHAR(120)
  • verification_statusENUM(pending..expired)
  • FK verified_byINT NULL → users
Cluster 2

Fleet & Business Assets (Vehicles & Lookup Tables)

Eliminates brand/model/transmission/fuel string duplication via dedicated lookup tables.

3NF Rationale: Previously brand → model → category created transitive dependencies inside vehicles. Now each asset references normalized vehicle_models, transmission_types, and fuel_types.
vehicle_makesLookup
  • PK idINT AUTO_INC
  • UQ nameVARCHAR(60)
  • country_of_originVARCHAR(60)
  • statusENUM(active, inactive)
vehicle_modelsModel Catalog
  • PK idINT AUTO_INC
  • FK make_idINT → vehicle_makes
  • FK category_idINT → vehicle_categories
  • UQ nameVARCHAR(80)
  • default_seatsTINYINT UNSIGNED
  • default_fuel_capacity_litersDECIMAL(5,1)
transmission_types & fuel_typesLookups
  • PK idTINYINT UNSIGNED
  • UQ codeVARCHAR(20)
  • UQ labelVARCHAR(50)
  • surcharge_per_literDECIMAL(8,2) (fuel_types)
vehiclesPhysical Asset
  • PK idINT AUTO_INC
  • FK model_idINT → vehicle_models
  • FK transmission_type_idTINYINT → transmission_types
  • FK fuel_type_idTINYINT → fuel_types
  • FK current_location_idINT → locations
  • UQ plate_numberVARCHAR(30)
  • daily_rateDECIMAL(10,2)
  • statusENUM(operational..retired)
Cluster 3

Operations & Transactions (Bookings, Rentals & Payments)

Tracks end-to-end reservation lifecycles, dispatch/return odometer logs, damage checklists, and immutable financial totals.

3NF Rationale: Pre-rental reservations, active rental handoffs, odometer/fuel return records, and multi-tender payments are decomposed into distinct lifecycle entities.
reservationsBooking Ledger
  • PK idINT AUTO_INC
  • UQ reference_numberVARCHAR(30)
  • FK customer_idINT → users
  • FK vehicle_idINT → vehicles
  • subtotal_before_taxDECIMAL(10,2)
  • vat_amount / vat_exempt_amountDECIMAL(10,2)
  • discount_amountDECIMAL(10,2)
  • final_totalDECIMAL(10,2)
rentals & pickup_recordsTurnover
  • PK idINT AUTO_INC
  • FK reservation_idINT → reservations
  • picked_up_at / due_atDATETIME
  • odometer_out / fuel_level_outINT / VARCHAR
  • statusENUM(active..overdue)
return_records & damage_reportsCheck-In
  • PK idINT AUTO_INC
  • FK rental_idINT → rentals
  • odometer_in / fuel_level_inINT / VARCHAR
  • estimated_costDECIMAL(10,2)
  • FK inspected_byINT → users
payments & payment_receiptsSettlements
  • PK idINT AUTO_INC
  • FK reservation_idINT → reservations
  • amountDECIMAL(10,2)
  • methodENUM(cash..online)
  • UQ receipt_numberVARCHAR(40)
Cluster 4

Pricing & Promotions (Philippine Statutory & Seasonal Rules)

Rule-based discount catalog supporting RA 9994 Senior Citizen, RA 10754 PWD, PH Holidays, long-term tiers, and promo codes.

3NF Rationale: Discount rules live independently of transactions; reservation_discounts freezes the applied rate and PHP savings at checkout so historical receipts never drift.
discount_typesCategory Lookup
  • PK idTINYINT UNSIGNED
  • UQ codeVARCHAR(40)
  • is_statutoryTINYINT(1)
  • requires_id_verificationTINYINT(1)
discount_rulesRule Definitions
  • PK idINT AUTO_INC
  • FK discount_type_idTINYINT → discount_types
  • calculation_modeENUM(percentage, fixed)
  • discount_valueDECIMAL(10,2)
  • vat_exempt_eligibleTINYINT(1)
  • min_rental_daysSMALLINT UNSIGNED
  • is_stackable / priorityTINYINT
holiday_calendar & promo_codesTriggers
  • PK idINT AUTO_INC
  • FK discount_rule_idINT → discount_rules
  • holiday_date / promo_windowDATE (holiday_calendar)
  • UQ codeVARCHAR(40) (promo_codes)
  • max_redemptions / currentINT UNSIGNED
reservation_discountsJunction Snapshot
  • PK idINT AUTO_INC
  • FK reservation_idINT → reservations
  • FK discount_rule_idINT → discount_rules
  • FK promo_code_idINT NULL → promo_codes
  • FK eligibility_verification_idINT NULL → verifications
  • computed_discount_amountDECIMAL(10,2)
  • computed_vat_exemptionDECIMAL(10,2)
